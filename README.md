# Le Petit Café — Café • Brunch • Gourmandises

Site vitrine one-page pour **Le Petit Café**, café fictif cosy au Puy-en-Velay, en rose poudré et marron, style rétro : hero en blob, bandeau défilant, services, menu et infos pratiques.

## Lancer
Ouvrir `index.html` dans le navigateur.

## Polices
Gros titres : Bright Regular (placer `Bright-Regular.woff2` à côté de `style.css`)
Texte : Inter / Manrope
